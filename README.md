# Python Day 129 - Merge Two Lists

This Python program combines two lists into one list using the `+` operator.

## Code Example

```python
list1 = [10, 20, 30]
list2 = [40, 50, 60]

merged_list = list1 + list2

print("Merged list:", merged_list)
```

## Output

```text
Merged list: [10, 20, 30, 40, 50, 60]
```

## Concepts Used

- Lists
- Variables
- `+` operator
- `print()` function

## How It Works

The program creates two lists containing numbers. The `+` operator combines both lists, and the result is stored in `merged_list`.
